# Иконки чата

Одна иконка = один `.svg` файл.

## Конвенция имени

Для **общих и офисных** иконок (формат-независимых и с текстовым
ярлыком формата):

```
<что-изображает>-<размер>.svg
```

Для **тематических** иконок (логотипы, узкие форматы — csv/ipynb/py)
суффикс `-<размер>` опускается: иконка одна в своём роде, размер в
имени ничего не говорит, и в `_ICON_URLS` ключ идёт без `-24`.

Примеры:
- `file-generic-24.svg` — общий документ (doc, log, json, xml, yaml, yml)
- `file-image-24.svg` — изображение (png, jpg, jpeg, gif, bmp, webp, svg)
- `file-code-24.svg` — исходный код (sql, js, ts)
- `file-docx-24.svg` — документ Word (docx)
- `file-xlsx-24.svg` — таблица Excel (xlsx)
- `file-pptx-24.svg` — презентация PowerPoint (pptx)
- `file-md-24.svg` — Markdown-документ (md)
- `file-txt-24.svg` — текстовый файл (txt)
- `file-pdf-24.svg` — PDF-документ (pdf)
- `csv.svg` — таблица CSV (csv) — тематическая, не из набора Heroicons
- `ipynb.svg` — Jupyter Notebook (ipynb) — ярлык «ipynb» внутри
- `py.svg` — Python-скрипт (py) — официальный логотип Python
- `zip.svg` — архивы (zip, rar, 7z, gz, tar) — WinRAR-стиль: стопка книг с ремнём

`file-spreadsheet-24.svg`, `file-presentation-24.svg` и
`file-archive-24.svg` удалены с диска: признаны визуально корявыми
и заменены на `csv.svg` (для `.xls`/`.ppt`) и `zip.svg` (для архивов).

`<размер>` — это viewBox и width/height (по умолчанию 24).

## Три вида иконок

В наборе сейчас три вида иконок по принципу выбора формата:

1. **С текстовым ярлыком внутри** — для конкретных офисных и узких
   текстовых форматов: `docx`, `xlsx`, `pptx`, `md`, `txt`, `pdf`, `ipynb`.
   Формат виден даже в мелком масштабе иконки (24×24 px), что важно
   для чата. У ярлыков длиннее 3 букв ширина зафиксирована через
   `textLength="11" lengthAdjust="spacingAndGlyphs"`: без этого подпись
   упирается в обводку корпуса (внутренняя ширина — 12.5 единиц) и
   разъезжается там, где вместо Arial подставится другой шрифт.

2. **Общие по форме** — для групп форматов с близкой природой:
   `generic` (документы и данные), `image`, `code` (sql/js/ts).
   Подходят, когда отдельная иконка под формат не нужна и форма уже
   передаёт тип. Для legacy Excel (`.xls`) и legacy PowerPoint (`.ppt`)
   общих иконок нет — `file-spreadsheet-24.svg` и `file-presentation-24.svg`
   удалены как визуально корявые, временно оба формата идут на `csv.svg`.
   Архивы (`.zip`/`.rar`/`.7z`/`.gz`/`.tar`) — `file-archive-24.svg`
   тоже удалена, все архивы идут на `zip.svg`.

3. **Тематические** — иконка-логотип, привязанная к одному формату и
   узнаваемая сама по себе: `csv.svg` (полосы строк), `ipynb.svg`
   (ярлык «ipynb» внутри корпуса), `py.svg` (официальный логотип
   Python), `zip.svg` (WinRAR-стиль: две книги с ремнём). Для таких
   иконок отдельный CSS-цвет обычно не нужен — `py.svg` и `zip.svg`
   сознательно игнорируют `currentColor` ради узнаваемости фирменных
   цветов.

Карта расширение → иконка живёт в
`static/js/shared/chat/chat-renderer.js` → `_ICON_FORM`.

## Цвет

Иконки первой и второй группы используют `stroke="currentColor"`,
поэтому цвет берётся из CSS-класса модификатора (например
`.chat-block-file-icon--pdf` ставит `color: #dc2626` и весь stroke
рендерится красным). У иконок с текстовым ярлыком подпись внутри
тоже наследует `currentColor`.

Иконки третьей группы `csv.svg` и `ipynb.svg` используют `currentColor`.
Исключения — `py.svg` (логотип Python: `#4584B6`/`#FFD43B`) и `zip.svg`
(WinRAR-стиль: `#B83A8A`/`#1E3F8C`/`#6B3F1D`/`#A8A8A8`/`#F4D03F`).
CSS-цвета `.chat-block-file-icon--py`/`.chat-block-file-icon--zip` на
эти иконки не действуют — узнаваемость фирменных цветов важнее общей
палитры карточки.

## Как добавить новую иконку

1. Положить `<имя>-<размер>.svg` (общая/офисная) или `<имя>.svg`
   (тематическая) в эту папку
2. В `static/js/shared/chat/chat-renderer.js` → `_ICON_URLS` добавить
   пару `'<ключ>': '<имя>.svg'`, и в `_ICON_FORM` — расширение → ключ.
3. Если расширение новое и его нет в `chat-blocks.css` →
   `.chat-block-file-icon--<ext>` с нужным цветом.
4. Hard refresh страницы (Ctrl+Shift+R)

## Как перерисовать

Просто открой нужный `.svg` в редакторе, поменяй `<path d="...">`, сохрани.
Браузер подхватит новую версию после hard refresh.
