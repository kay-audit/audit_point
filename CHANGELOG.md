# CHANGELOG

**Текущая версия: `17.1.2`.**

## Методология

- **MAJOR** — что-то существующее сломано или заменено несовместимо: удалён/изменён публичный REST-эндпоинт,
  переименован/удалён ключ конфигурации, заменён механизм авторизации, инфраструктурная зависимость стала
  обязательной без фолбэка, либо фундаментальный редизайн модели хранения/архитектуры приложения.
- **MINOR** — новая функциональность, ничего не ломающая: новый домен, новый модуль, новая возможность поверх
  существующей структуры.
- **PATCH** — багфиксы, рефакторинг без изменения поведения, тесты, документация, стилевые правки. Отдельно не
  расписаны (не входит в объём этой ревизии), так как изменения частые и входят в состав минора/мажора

## Как поднимать версию

Номер версии хранится **в одном месте** — `__version__` в `app/__init__.py`. `Settings.app_version` импортирует
его оттуда, дальше значение расходится само: health-эндпоинты, OpenAPI, `<meta name="app-version">` и
cache-busting статики (`?v=` из фильтра `versioned`). В `.env` версия не задаётся — `APP_VERSION` в шаблонах
закомментирована намеренно (детали — §9.4.4 в [`docs/guides/deploy-and-configuration.md`](docs/guides/deploy-and-configuration.md)).

**Когда.** Отдельным коммитом **на `master`, сразу после мержа** законченного блока работ (или после
законченной серии мини-коммитов прямо на `master`). В feature-ветках версию не трогают: хеш коммита для записи
известен только после мержа, а параллельные ветки иначе конфликтуют в `CHANGELOG.md` и плодят дубликаты.
Несколько подряд идущих правок одного калибра — один бамп в конце, а не по бампу на коммит.

**Что правится** (ровно два файла):

1. `app/__init__.py` — `__version__`.
2. `CHANGELOG.md` — строка «Текущая версия» вверху + запись: для MAJOR/MINOR отдельный раздел с обоснованием,
   для PATCH — строка `- X.Y.Z · \`hash\` — PATCH: …` под соответствующим разделом.

Дальше `pytest tests/test_version_consistency.py` (сверяет код ↔ CHANGELOG ↔ шаблоны `.env`) и коммит с
сообщением `Версия поднята до X.Y.Z` — без тела, обоснование живёт здесь.
